## 功能说明

Memos 26.11.0 支持作者通过 PRIVATE、PROTECTED、PUBLIC 及有空间放置时的 SPACE 受众控制普通访问。PUBLIC 的匿名可读性同时受实例访问模式控制。专门分享入口创建独立的只读令牌链接，使接收者无需登录即可读取指定笔记；该授权不会把原笔记改为 PUBLIC。复制普通笔记地址不增加访问权限。

## 实测摘要

2026-11-24，谢宇轩在 macOS arm64、SQLite、官方 26.11.0 发行版中使用两个 USER 账号及匿名独立浏览器会话验证，管理员另作特殊权限对照。完整提交号为 `b40d8a7b573774c52b022c8d6537d6baf2129dc0`。50 项接口状态断言通过，7 张浏览器截图覆盖作者访问、他人拒绝、匿名普通/分享访问、撤销后访问、分享管理和受众菜单。

PRIVATE 普通地址：A=200、B=403、匿名=401、管理员=200；私有实例的 PUBLIC 笔记匿名仍为 401，实例改为 PUBLIC 后为 200。有效分享对匿名返回 200，撤销及过期返回 404。SPACE 非成员 B=403，匿名=401；SPACE 和归档笔记不允许创建新分享。归档后旧分享不可用。

## 功能与代码

受众菜单 → UpdateMemo → 写权限及空间约束校验 → SQLite 更新 visibility。普通详情 GetMemo → buildMemoReadContext → CheckMemoReadContext。分享面板 → CreateMemoShare → 独立 memo_share 记录；匿名读取 GetSharedMemo 校验令牌、过期和生命周期；DeleteMemoShare 撤销后不再解析令牌。详细固定源码链接见 [UC-05 报告](uc-05-sharing.md)。
